# Data Sources — DraGold Community Core

This document lists the known data sources DraGold uses, their general characteristics, and important notes for contributors and fork maintainers.

**This is not legal advice.** Each data source has its own terms of service. If you use this codebase, you are responsible for complying with the terms of any data sources you connect to.

---

## Catalog data (cards, sets)

| Source | What it provides | Access | Notes |
|---|---|---|---|
| **TCGdex** | Card catalog, set lists, card metadata, images (EN + some JA) | Free API, no key required for basic use | Primary catalog source for the Community Core. Check [TCGdex](https://github.com/TCGdex) for current terms. Includes Cardmarket EUR and TCGPlayer USD pricing data. |
| **TCG Price Lookup** | Set catalog (list of sets per game) | API key required (`TCG_LOOKUP_API_KEY`) | Used by the `sync-sets` Edge Function to populate the `sets` table. Rate limited to ~200 req/day. |

### Third-party TCG data sources (validated, secondary)

| Source | Game | What it provides | Status |
|---|---|---|---|
| **PokéWallet** | Pokémon | Unified pricing across markets | Free tier available. Used for price data. |
| **BerryWallet** | One Piece | Pricing | One Piece-specific. |
| **optcgapi.com / onepiece-cardgame.com** | One Piece | Official images, card data | Official Bandai sources. Check terms before redistributing images. |
| **Scryfall** | MTG | Card data, bulk download | Scryfall has its own bulk data license. Check before bulk use. |
| **YGOPRODeck** | Yu-Gi-Oh! | Card data | Commonly used, free. |

## Image sources

DraGold uses an on-demand image cache. Images are fetched from various sources when needed and stored in Supabase Storage.

| Source | Game | What it provides | Notes |
|---|---|---|---|
| **TCGdex** | Multiple | Card images (EN, some JA) | Primary image source. Check TCGdex terms. |
| **images.pokemontcg.io** | Pokémon | Official Pokémon TCG images | Publicly accessible. |
| **optcgapi.com** | One Piece | Official One Piece card images | Bandai official. |
| **onepiece-cardgame.com** | One Piece | Official site images | Bandai official site. |

**Important**: Images are copyrighted by their respective owners. DraGold uses them as part of a TCG collection tool. If you fork this codebase and serve images, you are responsible for complying with the image source terms and copyright law.

## Pricing data

DraGold displays market prices from multiple sources. Prices are:

- **Third-party data** — not generated by DraGold
- **Time-sensitive** — prices change over time
- **Not financial advice** — displayed for collector reference

Price sources include TCGdex (which aggregates Cardmarket EUR and TCGPlayer USD), PokéWallet, and others. Each source has its own terms. Prices should be refreshed regularly via the scheduled workflows.

## What's NOT in this repository

- **No card database dump** — the actual card catalog lives in the Supabase database, not in Git
- **No user data** — collections, accounts, and preferences are in Supabase under RLS
- **No image cache** — images are fetched on-demand and cached in Supabase Storage
- **No bulk data downloads** — this repo does not include bulk card datasets

This is intentional. The Community Core is the application code, not the data.

---

## For fork maintainers

If you fork DraGold and run your own instance:

1. **Set up your own Supabase project** — you need your own database
2. **Configure your own API keys** — TCG LOOKUP, image cache, etc.
3. **Review data source terms** — make sure your use complies
4. **Evaluate trademark use** — your fork should have its own identity
5. **Set up your own scheduled jobs** — the GitHub Actions workflows reference the official project; you need your own CI configuration
6. **Respect rate limits** — don't hammer data sources
